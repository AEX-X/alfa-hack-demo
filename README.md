# Демо-стенд кредитного кабинета

Демо-прототип команды хакатона «Альфа-Будущее» (Альфа-Банк), кейс «Умный кредитный кабинет предпринимателя».

Это не сервис Альфа-Банка. Все компании, люди и суммы выдуманы, API заменено встроенными моками, данные хранятся только в вашем браузере. Настоящие пароли и данные сюда не вводите.

Открыть стенд: https://aex-x.github.io/alfa-hack-demo/

Демо-учётки выбираются на экране входа одним кликом: директора компаний из демо-сценариев, бухгалтер без права подписи и андеррайтер банка. Пульт сбоев внешних источников и сброс демо-данных: https://aex-x.github.io/alfa-hack-demo/#/demo

В репозитории только собранная версия фронтенда, исходный код в репозитории команды.
